# AI Website Auditor — No PageSpeed / No Playwright

A Streamlit website auditor using Requests, BeautifulSoup and Gemini.

It performs passive SEO, technical, accessibility, security-configuration,
robots/sitemap, and resource-performance checks.

It does NOT use PageSpeed API, Playwright, Chromium, or browser binaries.

Add to Streamlit Secrets:
GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
